# AI 보안과 윤리 · 대학원 입문 웹핸드북

논문을 처음 읽는 대학원생을 위한 한국어 학습 웹핸드북입니다.

웹 핸드북: https://ai.samuelchung.chatgpt.site

- 15주차 학습 안내, 40편의 논문 소개·요약, 341개 중복 정리 용어 항목
- 일반적인 뜻·어원/단어 구성·AI 공학 의미·논문 속 해석을 구분한 용어 풀이
- 39개 자가 점검 문제, 검색·북마크·개인 노트·학습 진행 기록·인쇄
- 로그인 없이 열람하는 강의·용어·재배포 허용 원문 자료
- 별도 승인 계정끼리 이용하는 주차별 번역본·요약 이미지·학습자료 공유 업로드
- PDF, PNG, JPEG, WebP, DOCX, HWP, HWPX 지원. 파일당 20 MiB

## 실행

공개 배포된 강의·용어·재배포 허용 원문 자료는 URL을 가진 누구나 로그인 없이 볼 수 있습니다. 정적 학습 화면은 public/index.html을 열어 오프라인으로도 볼 수 있습니다. 공유 업로드는 인증과 R2가 연결된 온라인 서버에서 별도로 승인된 계정만 이용할 수 있습니다.

온라인 개발은 Node.js 22.13 이상에서 npm ci 후 npm run dev로 시작합니다. 먼저 python3 rebuild.py로 src 변경을 public에 반영합니다. 빌드는 npm run build를 사용합니다. Sites 환경에서는 해당 환경의 공식 설치·빌드·배포 절차를 따라주세요. 이 공개 사본에는 기존 운영 사이트의 프로젝트 ID나 인증정보가 없습니다. 새 Site에 등록할 때 발급된 프로젝트 ID를 .openai/hosting.json에 설정해야 합니다.

## 업로드와 접근

강의 화면의 공개 범위와 공유 자료의 접근 권한은 분리됩니다. 공유 파일은 서버의 비공개 R2 BUCKET 바인딩에 저장합니다. 목록 조회·업로드·다운로드 API 모두 Sites가 전달한 인증 정보와 서버의 승인 계정 목록을 검사하고, 업로드의 동일 출처·요청 헤더·파일 형식·크기를 검증합니다. 다른 호스팅 환경으로 이전할 때는 동등한 서버 측 인증을 구현해야 합니다. 외부 요청의 인증 헤더를 그대로 신뢰하는 공개 서버에 배포하지 마세요.

공유 자료를 사용하려면 서버 런타임의 비밀 설정에 HANDBOOK_MATERIALS_ALLOWED_EMAILS를 JSON 문자열 배열로 등록해야 합니다. 형식 예시는 ["learner@example.invalid","teacher@example.invalid"]이며, 모두 가짜 주소입니다. 실제 승인 계정 목록은 소스·클라이언트 번들·GitHub에 넣지 마세요. 이 저장소에는 운영 환경의 설정값이나 실제 계정 목록이 포함되지 않습니다. 새 배포에서는 사용할 호스팅의 비밀 설정 기능으로 직접 구성해야 합니다.

목록은 공백을 정리한 이메일을 대소문자 구분 없이 정확히 일치시킵니다. 미인증 요청은 401, 목록에 없는 로그인 계정은 403으로 거부합니다. 설정 누락·빈 목록·잘못된 JSON은 접근을 열지 않고 503으로 차단합니다. 로그인 링크는 공유 자료 영역에만 표시되므로 공개 강의 탐색은 계속할 수 있습니다.

업로드한 자료는 별도로 승인된 계정끼리만 공유합니다. 개인 학습 기록은 브라우저에만 남습니다. 실제 업로드 파일과 개인 기록은 이 저장소에 포함되지 않습니다. GitHub Pages 정적 호스팅만으로는 공유 업로드가 작동하지 않습니다.

100개가 이미 등록된 주차는 새 업로드 접수를 제한합니다. 동시 요청에서는 이 기준을 소폭 초과할 수 있습니다. 파일 검사는 백신 검사가 아니며, 공유 권한이 있는 자료만 올리고 다운로드 후 안전성을 확인해야 합니다.
