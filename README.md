# AI 보안과 윤리 · 대학원 입문 웹핸드북

논문을 처음 읽는 대학원생을 위한 한국어 학습 웹핸드북입니다.

## 주요 기능

- 15주차 학습 안내, 40편의 논문 소개·요약, 341개 중복 정리 용어 항목
- 일반적인 뜻·어원/단어 구성·AI 공학 의미·논문 속 해석을 구분한 용어 풀이
- 39개 자가 점검 문제, 검색·북마크·개인 노트·학습 진행 기록·인쇄
- 각 주차의 번역본·요약 이미지·학습자료 공유 업로드
- PDF, PNG, JPEG, WebP, DOCX, HWP, HWPX 지원. 파일당 20 MiB

## 실행

정적 학습 화면은 public/index.html을 열어 오프라인으로 볼 수 있습니다. 공유 업로드는 인증과 R2가 연결된 온라인 서버에서만 작동합니다.

온라인 개발은 Node.js 22.13 이상에서 npm ci 후 npm run dev로 시작합니다. 먼저 python3 rebuild.py로 src 변경을 public에 반영합니다. 빌드는 npm run build를 사용합니다. Sites 환경에서는 해당 환경의 공식 설치·빌드·배포 절차를 따라주세요. 이 공개 사본에는 기존 운영 사이트의 프로젝트 ID나 인증정보가 없습니다. 새 Site에 등록할 때 발급된 프로젝트 ID를 .openai/hosting.json에 설정해야 합니다.

## 업로드와 접근

공유 파일은 서버의 비공개 R2 BUCKET 바인딩에 저장합니다. API는 Sites가 전달한 인증 정보를 검사하고 업로드의 동일 출처·요청 헤더·파일 형식·크기를 검증합니다. 다른 호스팅 환경으로 이전할 때는 동등한 서버 측 인증을 구현해야 합니다. 외부 요청의 인증 헤더를 그대로 신뢰하는 공개 서버에 배포하지 마세요.

업로드한 자료는 해당 사이트에서 허용한 사용자끼리 공유합니다. 개인 학습 기록은 브라우저에만 남습니다. 실제 업로드 파일과 개인 기록은 이 저장소에 포함되지 않습니다. GitHub Pages 정적 호스팅만으로는 공유 업로드가 작동하지 않습니다.

100개가 이미 등록된 주차는 새 업로드 접수를 제한합니다. 동시 요청에서는 이 기준을 소폭 초과할 수 있습니다. 파일 검사는 백신 검사가 아니며, 공유 권한이 있는 자료만 올리고 다운로드 후 안전성을 확인해야 합니다.

## 자료 범위와 권리

사이트에서 재배포가 명확히 허용된 논문 18편과 NIST AI RMF 1.0만 원문 PDF로 포함했습니다. 나머지는 공식 출처 링크와 접근 범위를 제공합니다. Science 2024의 Considerations for Governing Open Foundation Models는 초록 수준으로 표시했고, ISO/IEC 42001 유료 원문은 포함하지 않았습니다. 원문과 각 자료의 권리 조건은 public/data.js 및 학습 화면의 출처·라이선스 표기를 확인해 주세요.

NIST 자료 표기: Republished courtesy of the National Institute of Standards and Technology.

이 저장소의 공개 여부는 제3자 저작물에 대한 추가 이용 허락을 의미하지 않습니다. 포함된 라이브러리·스타터의 고지와 개별 논문 라이선스를 지켜 주세요. 프로젝트 전체에 임의의 오픈소스 라이선스를 지정하지 않았습니다.
